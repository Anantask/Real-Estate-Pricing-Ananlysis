# Real-Estate-Pricing-Ananlysis
 Real Estate pricing analysis works on attributes such as availabilty,flat size(BHKs),location,total sqft and comparing all this the data it analysis the pricing rates based on the given parameters and help us analysing which areas to focus on.

 
This project analyzes real estate pricing in Bengaluru (Bangalore). It focuses on:
Cleaning messy housing data (handling missing values, inconsistent formats).
Feature engineering (bhk, price_per_sqft).
Outlier detection and removal.
Preparing a clean dataset (~7k rows) ready for machine learning models.
The notebook demonstrates real-world data preprocessing challenges and how to create reliable features for price prediction.
